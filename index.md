# Snake Runner: IDE personal de Python

### **[>> Ir al editor](run)**

Este proyecto tiene por objetivo proveer una plataforma simple, pero segura para que mis alumnos de programación puedan probar su código,
ya que no cuentan con un dispositivo capaz de ejecutar Python localmente.

No está diseñado para el público en general, y probablemente siga siendo experimental. El HTML está hecho con CodeMirror y PyScript.
He utilizado ayuda de otros proyectos y ejemplos para juntar el código final.
